# 클립보드 · 파일 ⇄ QR 동영상

> **폰에서 바로 받기:** `phone/` 폴더의 웹앱이 PC 화면의 QR 재생을 폰 카메라로 실시간 해독해 파일로 복원합니다.
> GitHub Pages 주소: https://dykim-sfive.github.io/qrcheck/phone/ (안드로이드 크롬, 자세한 내용은 [phone/README.md](phone/README.md))
> 송신(QR 재생)은 아래의 PC용 Python 서버가 맡습니다.

파일이나 클립보드 내용을 ZIP으로 압축하고, 애니메이션 QR로 보여준 뒤, 카메라로 찍은 영상/사진에서 복원합니다.

## 실행
```bash
python3 -m venv .venv
source .venv/bin/activate           # Windows: .venv\Scripts\activate
pip install -r requirements.txt     # segno, zxing-cpp, opencv-python-headless, numpy
python3 server.py                   # http://127.0.0.1:8765  (포트 변경: python3 server.py 9000)
```
브라우저에서 `http://127.0.0.1:8765` 를 엽니다. 서버는 이 컴퓨터(127.0.0.1)에서만 접속됩니다.

## 구성
| 파일 | 역할 |
|---|---|
| `server.py` | 표준 라이브러리 웹서버 (`/api/pack`, `/api/qr/encode`, `/api/qr/decode`, `/api/qr/reset`, `/api/status`) |
| `index.html` | UI: ① 클립보드 검증(붙여넣기 → 포맷/내용 확인 → 압축) ② QR 동영상(송신·수신, 압축 파일 다운로드) |
| `qr_codec.py` | Base45, fountain code(프레임 일부를 놓쳐도 복원), QR 생성(segno), 영상/사진 해독(zxing-cpp, 멈춤 방지용 별도 프로세스) |
| `pack.py` | 여러 항목을 ZIP 하나로 압축 (표준 라이브러리) |
| `phone/` | 폰용 수신 웹앱 (정적 파일, 서버 불필요) |

## 사용 흐름
1. **클립보드 탭**: 클릭 후 Ctrl/⌘+V → 포맷별 종류·크기·내용 확인 → 필요한 항목만 체크 → "다음 → 압축하고 QR 동영상으로"
2. **QR 탭 (송신)**: 파일을 고르면 준비만 되고, 설정(QR 크기·오류 정정·여분 프레임·표시 크기/위치·초당 프레임)을 마친 뒤 **▶ 시작**을 누르면 QR 재생이 시작됩니다. 표시 크기·위치, QR 크기, 오류 정정, 여분 프레임, 초당 프레임을 조절할 수 있고, 지금 보내는 파일(`clipboard.zip` 등)을 바로 내려받을 수 있습니다.
3. **QR 탭 (수신)**: 폰으로 촬영한 영상/사진을 올리면 블록이 쌓이고, 서로 다른 프레임이 (블록 수 + 2~3)개 모이면 복원됩니다. 여러 영상/사진은 자동 병합됩니다.

## 참고 · 촬영 팁
- **프레임 건너뛰기는 "모든 프레임"(기본)을 권장합니다.** 한두 바퀴만 찍은 영상은 프레임 하나를 건너뛰어도 복원에 실패할 수 있습니다.
- **2바퀴 이상** 찍으세요. 한 바퀴 시간(송신 화면에 표시)의 2배 이상을 촬영하면 놓친 프레임이 다음 바퀴에서 채워집니다.
- 해독은 영상을 3~5배 확대해서 시도합니다. 모듈당 3px 미만이면 어려우니 표시 크기를 키우거나 QR 크기를 "작게"로 낮추세요 (화면에 경고 표시).
- 메신저(카카오톡 등)로 보내면 해상도가 낮아지고 재압축됩니다. 가능하면 원본 영상을 직접 옮기세요.
- 아이폰 `.mov`(HEVC)를 OpenCV가 못 읽으면 mp4(H.264)로 변환하세요.
- 일부 프레임에서 해독 라이브러리가 멈추는 경우가 있어, 해독은 별도 프로세스에서 하고 프레임당 3초가 넘으면 그 프레임만 건너뜁니다 (진행 정보의 `hang`).
